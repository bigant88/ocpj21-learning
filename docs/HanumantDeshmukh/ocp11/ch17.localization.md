## 1. Date & Time Formatting
- Sử dụng DateTimeFormatter (không có DateFormatter).
```java
DateTimeFormatter dtf = DateTimeFormatter.ofPattern("dd-MM-yyyy - hh:mm:ss");
LocalDateTime now = LocalDateTime.now();
System.out.println(now.format(dtf)); // 22-09-2023 - 08:44:55
```
## 2. Number Formatting
- DecimalFormat
    - "#" → bỏ qua nếu không có số.
    - 0 → thêm số 0 nếu không có số.
```java
double wealth = 500_000.45;
NumberFormat nf = new DecimalFormat("###,###,###.000000");
System.out.println(nf.format(wealth)); // 500,000.450000
```
- CompactNumberFormat
    - Rút gọn số lớn (K, M).
```java
NumberFormat compact = NumberFormat.getCompactNumberInstance(Locale.getDefault(), NumberFormat.Style.SHORT);
System.out.println(compact.format(1_000_000)); // 1M
```
##  3. Currency Formatting
- Dựa vào Locale:
```java
Locale.setDefault(Category.FORMAT, Locale.ITALY);
System.out.println(NumberFormat.getCurrencyInstance().format(12.3)); // 12,30 €
```
## 4. Locale
- Định dạng hợp lệ: it, it_IT (ngôn ngữ thường, quốc gia viết hoa).
```java
Locale locale = new Locale("en", "US"); // Tạo Locale đúng cách:
```
- Locale Category:
    - DISPLAY: hiển thị thông tin.
    - FORMAT: định dạng số, ngày, tiền tệ.
## ✅ Điểm bẫy OCP
- DateTimeFormatter là immutable.
- Locale phải đúng định dạng (it_IT, không phải IT_it).
- CompactNumberFormat chỉ làm tròn trong phạm vi 3 chữ số.
- ResourceBundle fallback về default locale nếu không tìm thấy.
## ResourceBundle Lookup Flow 
- 1. Tìm theo locale được truyền
- 2. Nếu không thành công → chuyển sang Default Locale
- 3. Cuối cùng → fallback về baseName.properties
- 4. Nếu vẫn không có → MissingResourceException

## Ví dụ: 
```java
ResourceBundle.getBundle("msgs", Locale.of("fr", "CA"));

msgs_fr_CA.properties
        ↓
msgs_fr.properties
        ↓
msgs.properties
        ↓
MissingResourceException
```
