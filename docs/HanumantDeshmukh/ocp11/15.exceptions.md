# Bảng so sánh Checked vs Unchecked Exceptions (Java)

| Tiêu chí | Checked Exception | Unchecked Exception |
|--------|------------------|--------------------|
| Kế thừa từ | `Exception` (không qua `RuntimeException`) | `RuntimeException` |
| Thời điểm xảy ra | Compile-time & Runtime | Runtime |
| Bắt buộc xử lý | ✅ Có (`try-catch` hoặc `throws`) | ❌ Không |
| Compiler kiểm tra | ✅ Có | ❌ Không |
| Mục đích | Lỗi **có thể dự đoán & phục hồi** | Lỗi **logic / lập trình** |
| Do ai gây ra | Môi trường / I/O / tài nguyên | Lập trình viên |
| Ảnh hưởng compile | Không xử lý → **compile error** | Compile vẫn OK |
| Hay gặp trong OCP | ⭐⭐⭐ | ⭐⭐⭐⭐ |
---
## Ví dụ Checked Exception
```java
import java.io.*;
void readFile() throws IOException {
    FileReader fr = new FileReader("test.txt");
}
❌ Không xử lý → Compile-time error
```
## Ví dụ Unchecked Exception
```java
int x = 10 / 0; // ArithmeticException
✔️ Compile OK → ❌ Runtime crash
```
## Checked Exceptions
- IOException
- SQLException
- ClassNotFoundException
- InterruptedException
- FileNotFoundException

## Unchecked Exceptions - NAICAN
- NullPointerException
- ArrayIndexOutOfBoundsException
- IllegalArgumentException
- ClassCastException
- ArithmeticException
- NumberFormatException

# quy tắc throw exception khi override method trong Java
- Không được throw checked exception rộng hơn
- Được bỏ hoàn toàn checked exception
- Có thể throw bất kỳ RuntimeException, kể cả khi class cha không throws gì.
- Nếu class cha không throws checked exception -> Class con KHÔNG được thêm checked exception mới.
- Áp dụng cho multiple inheritance qua interface: 
  - Nếu override method từ nhiều interface: Chỉ được throws exception chung (intersection) của tất cả method.
## Quy tắc nhớ nhanh (rất hay ra thi)
- Override = same or sub-checked exceptions
- Unchecked exception = free

## Ghi nhớ nhanh cho OCP 🎯
- Checked → bắt buộc xử lý try-catch
- Unchecked → compiler bỏ qua
## OCP rất hay hỏi:
- Override method với throws
- Compile OK nhưng runtime fail
- Thứ tự try-with-resources + exception
- 🧠 Mẹo nhớ:
  - Checked = Compiler cares
  - Unchecked = You care
