# ✅ Java Date & Time Cheat Sheet

## 1. Core Classes
| Class            | Description                                      |
|------------------|--------------------------------------------------|
| `LocalDate`      | Date only (YYYY-MM-DD), no time or zone         |
| `LocalTime`      | Time only (HH:mm:ss), no date or zone           |
| `LocalDateTime`  | Date + Time, no zone                            |
| `ZonedDateTime`  | Date + Time + Zone                              |
| `Instant`        | A moment in time in UTC (GMT)                  |
- (Local = no time zone)
---

## 2. ZonedDateTime Example
```java
ZonedDateTime.now(); 
// 2023-05-14T19:56:46.627004+02:00[Europe/Zurich]
```

## 4. Duration vs Period

| Feature      | Duration                     | Period                  |
|-------------|-----------------------------|-------------------------|
| Measures    | Seconds, nanos             | Years, months, days    |
| Works with  | `LocalDateTime`, `Instant` | `LocalDate`            |
| Example     | `PT24H`                    | `P2Y3M6D`              |
- Duration Example:
```java
Duration.ofSeconds(758768437); // PT210769H37S
```
- Period Example:
```java
Period.ofDays(1); // P1D
```
- ⚠️ Period.of() does NOT chain:
```java
Period.ofYears(1).ofMonths(2).ofDays(1); // P1D
```
- Duration → starts with PT (e.g., PT24H)
-  Period → starts with P (e.g., P2Y3M6D)
## Instant
- Represents a moment in UTC.
- Format: YYYY-MM-DDTHH:mm:ss.SSSZ
- Example:
```java
Instant.now(); // 2024-01-18T11:02:16.628552400Z
Instant.parse("2024-03-01T14:02:30Z");
```
# Top Tips & Tricks for OCP Date/Time Questions
## 1 Support Units
- Duration -> works with **time-based** units (seconds, nanos), **NOT** with LocalDate
- Period -> work with date-based units (years, months, days), NOT with LocalDateTime or Instant
```java
LocalDate date = LocalDate.now();
date.plus(Duration.ofDays(1)); // Throws UnsupportedTemporalTypeException
```
## 2 Static vs Instance Methods
- Period.ofYears(1).ofMonths(2).ofDays(3) → Only last call counts → P3D.
- Chaining works only with instance methods
```java
Period p = Period.ofDays(1).plusYears(2).plusMonths(3); // P2Y3M1D
```
## 3. Instant Limitations
- Instant represents a moment in UTC.
- Cannot add years or months to an Instant
- Can add day or smaller unit
```java
Instant.now().plus(1, ChronoUnit.DAYS); // OK
```
## 4. ZonedDateTime vs OffsetDateTime
- ZonedDateTime includes time zone ID (e.g., [Europe/Zurich]).
- OffsetDateTime includes only offset (e.g., +02:00), no zone name.
- Exam trap: They look similar but behave differently when converting to Instant.
## 5. Formatting and Parsing
- DateTimeFormatter is immutable and thread-safe.
```java
DateTimeFormatter.ISO_LOCAL_DATE; // 2025-12-15
LocalDate.parse("2025-12-15"); // OK
```
## 6. ChronoUnit.between()
- Works with temporal types that support the unit:
```java
long days = ChronoUnit.DAYS.between(LocalDate.now(), LocalDate.now().plusDays(5)); // 5
```
## 7. Watch Out for Immutable Behavior
- All date/time classes are immutable. Methods like plus() and minus() return a new object, not modify the original.
## 8  Bẫy OCP
- Nhiều người nghĩ Duration.ofDays(1) và Period.ofDays(1) giống nhau → Sai.
- Duration tính theo thời gian thực (24h) → bị ảnh hưởng bởi DST.
- Period tính theo ngày lịch → không bị ảnh hưởng bởi DST.
 ```java
//Given: Daylight Savings Time ends on Nov 6 at 2 AM in US/Eastern time zone. As a result, 2 AM becomes 1 AM.  In other words, one minute after 1.59 AM, the clock shows 1 AM instead of 2 AM.
LocalDateTime ldt = LocalDateTime.of(2022, Month.NOVEMBER, 5, 10, 0);

// 1. Dùng Duration
ZonedDateTime date = ZonedDateTime.of(ldt, ZoneId.of("US/Eastern"));
date = date.plus(Duration.ofDays(1));
System.out.println(date);
//2022-11-06T09:00-05:00[US/Eastern]

// 2. Dùng Period
date = ZonedDateTime.of(ldt, ZoneId.of("US/Eastern"));
date = date.plus(Period.ofDays(1));
System.out.println(date);
//2022-11-06T10:00-05:00[US/Eastern]
```
