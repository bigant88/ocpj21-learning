# 1 LAMBDAS – BẢN CHẤT & CÚ PHÁP
- 👉 Lambda là một đoạn code không tên, được truyền đi để chạy sau.
```java
a -> a.canHop();
// tương đương 
boolean test(Animal a) {
    return a.canHop();
}
```
- Lambda KHÔNG tự đứng một mình
- Luôn gắn với Functional Interface

- Cú pháp đầy đủ
```java
(parameters) -> { body }
```
- Các phần có thể bỏ

  | Thành phần      | Khi nào bỏ được             |
  | --------------- | --------------------------- |
  | Kiểu tham số    | Java tự suy luận            |
  | Dấu ngoặc `()`  | Khi chỉ có 1 tham số        |
  | `{}` + `return` | Khi body chỉ có 1 biểu thức |

- Các dạng tương đương (RẤT HAY RA):
```java
a -> a.canHop()
(Animal a) -> a.canHop()
a -> { return a.canHop(); }
(Animal a) -> { return a.canHop(); }
```
- Cú pháp Lambda sai (rất hay bị hỏi)
```java
x, y -> x.startsWith("a")     // ❌ thiếu (), chỉ bỏ () được khi có 1 tham số và không viết kiểu tham số
x -> { x.isEmpty(); }        // ❌ thiếu return
String x -> x.isEmpty()      // ❌ thiếu ()
```

# 2 FUNCTIONAL INTERFACE (SAM RULE)
- Functional Interface = interface có CHÍNH XÁC 1 abstract method 
- SAM – Single Abstract Method
- @FunctionalInterface
  - Giúp compiler kiểm tra
  - Không bắt buộc
- Những method KHÔNG tính vào SAM: 
  - default
  - static
  - private
  - private static
  - các method giống Object:
    - toString()
    - equals(Object)
    - hashCode()
- Bẫy thi kinh điển
```java
interface Hibernate {
   boolean equals(Hibernate h); // ❌ KHÔNG phải Object
   void rest();
}
// Chỉ boolean equals(Object o) mới là method đặc biệt được kế thừa từ Object
//➡️ 2 abstract methods → ❌ không phải functional interface
```

# 4 BUILT-IN FUNCTIONAL INTERFACES (PHẢI THUỘC)
- 4 interface cốt lõi

 | Interface     | Params | Return  | Method |
  | ------------- | ------ | ------- | ------ |
  | Supplier<T>   | 0      | T       | get    |
  | Consumer<T>   | 1      | void    | accept |
  | Predicate<T>  | 1      | boolean | test   |
  | Function<T,R> | 1      | R       | apply  |
- Bi-version: 
  - BiConsumer<T,U>
  - BiPredicate<T,U>
  - BiFunction<T,U,R>
- Operator (Function đặc biệt)

    | Interface         | Đặc điểm  |
    | ----------------- | --------- |
    | UnaryOperator<T>  | T → T     |
    | BinaryOperator<T> | (T,T) → T |
- Cách nhận diện trong đề thi: 
  - 1️⃣ Đếm số tham số
  - 2️⃣ Xem có return không
  - 3️⃣ Return type là gì

# 6 VARIABLES TRONG LAMBDA (BẪY RẤT NHIỀU)

| Biến              | Có dùng trong lambda?       |
| ----------------- | --------------------------- |
| Instance variable | ✔                           |
| Static variable   | ✔                           |
| Local variable    | ✔ nếu **effectively final** |
| Method parameter  | ✔ nếu **effectively final** |
| Lambda parameter  | ✔                           |

- Effectively final: Local variable hoặc Method parameter Không bị gán lại sau khi khởi tạo
```java
int x = 5;
p -> x + 1;   // ✔
x = 6;        // ❌ nếu có lambda dùng x
// Lỗi compile xuất hiện ở lambda, không phải chỗ gán
// x 
```
- Phải sửa thành : 
```java
 public static void main(String[] args) {
        int x = 5;
        int finalX = x;
        DoubleToIntFunction doubleToIntFunction = p -> finalX + 1;// ✔
        x = 6;
    }
```
# 3 METHOD REFERENCES (RẤT HAY RA)
### Method Reference là gì? (BẢN CHẤT)
- Method reference = lambda rút gọn
- Điều kiện để dùng Method Reference: 
  - Chỉ gọi một method
  - Không thêm logic (if, +, -, gán, …)
  - Chữ ký (parameters + return type) khớp Functional Interface
```java
// ❌ Ví dụ không đổi được:
x -> x + 1
x -> { System.out.println(x); log(x); }
```
### Cú pháp tổng quát
```java
TênThamChiếu::TênMethod
```
| Trước `::` | Sau `::`                           |
| ---------- | ---------------------------------- |
| Class      | static method                      |
| Object     | instance method                    |
| Class      | instance method (object chưa biết) |
| Class      | constructor (`new`)                |

###  4 loại BẮT BUỘC NHỚ

  | Loại                           | Ví dụ                 |
  | ------------------------------ | --------------------- |
  | Static                         | `Math::round`         |
  | Instance (object cụ thể)       | `System.out::println` |
  | Instance (đối tượng chưa biết) | `String::isEmpty`     |
  | Constructor                    | `String::new`         |
- Ví dụ chuyển đổi
```java
x -> System.out.println(x)
System.out::println
// 
(s1, s2) -> s1.concat(s2)
String::concat
```
