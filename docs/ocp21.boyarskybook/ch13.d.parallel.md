# WORKING WITH PARALLEL STREAMS
## Parallel Stream
- Xử lý nhiều phần tử cùng lúc
- Sử dụng nhiều thread
- KHÔNG đảm bảo thứ tự
- Kiểm tra stream có song song hay không: 
```java
stream.isParallel();
// true → parallel stream
// false → serial stream
```
## 3. Lợi ích & rủi ro của Parallel Stream
- Lợi ích
  - Tăng hiệu năng
  - Tận dụng CPU đa lõi
  - Không cần quản lý thread thủ công
- Rủi ro
  - ❌ Thứ tự không xác định
  - ❌ Dễ gây side effect
  - ❌ Khó debug
## 4. Ví dụ hiệu năng
- Hàm giả lập công việc nặng
```java
private static int doWork(int input) {
   try {
      Thread.sleep(5000);
   } catch (InterruptedException e) {}
   return input;
}
```
- Serial stream
```java
List.of(1,2,3,4,5)
   .stream()
   .map(w -> doWork(w))
   .forEach(System.out::print);
// ⏱ ~25 giây
//✔ Thứ tự đúng
```
- Parallel stream
```java
List.of(1,2,3,4,5)
   .parallelStream()
   .map(w -> doWork(w))
   .forEach(System.out::print);
// ⏱ ~5 giây
// ❌ Thứ tự ngẫu nhiên
```
- 📌 Kết luận
> Parallel stream giống như submit nhiều task vào thread pool

## 5 Giữ thứ tự khi dùng Parallel Stream
```java
.forEachOrdered(System.out::print);
// Giữ đúng thứ tự
// Mất bớt hiệu năng
```
- 📌 Exam tip
  - forEach() → unordered
  - forEachOrdered() → ordered
